# Mechanism：机制与关系

当主要理解任务是解释对象如何相互作用、结果如何产生及成立条件时使用。出现术语或公式本身不决定此 Profile。

## 编辑重点

- 围绕核心问题组织必要对象、作用路径和结果，将定义放在首次使用处，依赖关系先于复杂推导。
- 区分输入、状态、作用、输出及反馈；仅在来源包含这些关系时展开，不强填系统框架。
- 保留改变机制成立范围的条件、反例，以及帮助理解的代表性推导或例子。
- 快速掌握提炼核心机制及适用边界；内容地图展示主要依赖或作用路径；深入阅读解释依据和细节。

## 可选表达

优先考虑 State / Relationship Map 表达作用、反馈或资源循环，Before → Trigger → After 表达状态变化。公式、正常段落和局部对照仍可承担推导；其他视觉语法按需要使用。

## 失真提醒

不将相关性、类比或假设转为确定因果；不凭熟悉的理论补齐来源缺失的对象、公式项或反馈路径。图中保留关系性质与条件，不能用抽象标签和箭头代替解释。
