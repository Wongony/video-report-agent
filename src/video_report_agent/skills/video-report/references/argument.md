# Argument：议题、立场与依据

当主要理解任务是理解某个判断、不同立场及其论据时使用。单人表达也可适用；多人对话不必然适用。

## 编辑重点

- 以核心议题组织材料，将相关人物的判断、理由、例子和回应放在同一议题下，避免按发言顺序重新抄录。
- 区分事实陈述、价值判断、个人经历、预测和建议，保留各自归属与限定。
- 分歧来自前提、证据、目标或价值取向时，说明来源实际支持的差异；只有材料支持时才归纳共识和未解决问题。
- 快速掌握呈现主要判断与关键分歧；内容地图展示议题之间的联系；深入阅读保留论证、回应及代表性例子。

## 可选表达

多人围绕共同议题表态时，可用 Issue Matrix 对照立场与依据；单人论证可用“判断—依据—限定”的连贯结构，无需虚设对方。局部经历、机制和条件选择可使用其他视觉语法。

## 失真提醒

不把主持人的提问写成其主张，不将二手转述当作被引人物原话；未回应不代表默认赞同。保留观点随讨论变化的语境，不为矩阵整齐制造对立、共识或对等证据。
